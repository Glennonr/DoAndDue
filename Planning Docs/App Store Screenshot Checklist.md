# Do & Due App Store Screenshot Checklist

_Last updated: August 17, 2026_

Use this as the working checklist for the first App Store screenshot set.

## Screenshot Goals

The screenshot set should show the actual app, not marketing screens. It should make the product understandable in a few seconds:

* What needs attention today
* How recurring tasks work
* How task detail/history works
* That completed work is visible in Done
* That widgets are supported

## Recommended Screenshot Order

1. **Today**
   Show Overdue, Today, Anytime, and Upcoming if possible.

2. **Task Editor**
   Show the repeat selector and due/reminder controls. Prefer a recurring task because that is the app's core differentiator.

3. **Task Detail**
   Show next due date, reminder, total completions, and history.

4. **Done**
   Show recent completions.

5. **Widget**
   Show the medium Home Screen widget with several tasks.

## Suggested Demo Data

Use realistic, non-sensitive task names:

* Change HVAC filter
* Renew vehicle registration
* Submit weekly timesheet
* Organize utility closet
* Schedule dentist cleaning
* Check smoke detectors

Avoid screenshots containing personal names, addresses, account numbers, or real bills.

## Visual Requirements

* Capture both light and dark mode if we want a broader set, but keep the first set focused and consistent.
* Use current final UI, not planning mockups.
* Make sure the debug pending-reminders bell is not visible in Release screenshots.
* Make sure notification permission prompts are not visible.
* Make sure widgets have current data and are not blank.
* Use the final app icon before capturing screenshots.

## Manual Capture Steps

1. Install a Release or archive-equivalent build.
2. Create the suggested demo tasks.
3. Complete a few tasks so Done and Task Detail history are populated.
4. Add the medium widget to the Home Screen.
5. Capture screenshots for each required display size in App Store Connect.
6. Review every screenshot at full size for clipped text, stale debug UI, private data, or unreadable contrast.

## App Store Connect Notes

Screenshots should match the submitted build. If UI changes after screenshots are taken, recapture the affected screens.
